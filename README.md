# Playwright E2E Automation Project

## Overview

This project demonstrates end-to-end UI automation using Playwright and JavaScript.

The automation covers application workflows from the user interface and validates expected results through automated tests.

## What I Test

- Login functionality
- Positive and negative scenarios
- UI interactions
- Form validation
- End-to-end user workflows
- Assertions and expected results
- Regression scenarios
- Cross-browser test execution

## How to Run

Install dependencies:

```bash
npm install
```

Run all tests:

```bash
npx playwright test
```

Run tests with the browser visible:

```bash
npx playwright test --headed
```

View the HTML report:

```bash
npx playwright show-report
```
